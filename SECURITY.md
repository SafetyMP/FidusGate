# Security Policy

## Supported versions

Only the latest active release on `main` is supported for security updates:

| Version | Supported |
| ------- | --------- |
| v1.x    | Yes       |
| < v1.0  | No        |

## Reporting a vulnerability

**Do not open a public GitHub issue** for undisclosed security vulnerabilities.

### Preferred channel (private)

Submit a private report via **[GitHub Security Advisories](https://github.com/SafetyMP/FidusGate/security/advisories/new)**.

If that link returns 404, private vulnerability reporting is not enabled yet — ask a repo admin to turn on **Settings → Code security → Privately report a security vulnerability**, then retry the link above.

### Email (currently unavailable)

`security@fidusgate.io` is **not** a working inbox: the `fidusgate.io` domain has no public DNS/MX records. Do not use it until this policy is updated with a verified address.

Include reproduction steps, impact, and affected components where safe. We aim to acknowledge within **72 hours** and coordinate remediation under a **90-day responsible disclosure window** before publishing details.

Thank you for helping keep FidusGate secure.
